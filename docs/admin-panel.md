# Админ-панель для админов

## Доступ

1. Войдите в dashboard
2. Нажмите «Admin Panel»
3. Выполните разблокировку сервера (Unlock) — выберите сервер, к которому у вас есть права
4. Сессия unlock живёт 60 минут, затем нужно разблокировать снова

## Разделы

### Admins

- **Список** — все админы выбранного сервера
- **Управление** — действия над админом (по нику): просмотр, история, нормы и т.п.
- **Добавление** — добавить нового админа

### Logs

- **Actions** — действия админов (level 6, GA)
- **Warnings** — предупреждения (level 6, GA)
- **Purchases** — покупки (level 6, GA)
- **Removed** — удалённые админы (level 7)
- **GA Actions** — действия кураторов (level 8)

### Extended

- **Players** — поиск игроков (простой и расширенный)
- **Player stats** — детальная статистика по ID
- **Nicknames** — логи смены ников
- **Unbans** — логи разбанов
- **Bans** — перманентные баны, редактирование причины
- **IP Bans** — баны по IP
- **Matchmaking** — статистика матчмейкинга
- **Money transfers** — переводы денег
- **Accessories** — логи аксессуаров

### Manage

- **News** — управление новостями (level 8, GA)
- **Servers** — настройки серверов (level 8, GA)

## Уровни доступа

| Уровень | Описание |
|---------|----------|
| 6 (+ GA) | Логи actions, warnings, purchases |
| 7 | Removed, Extended (players, nicknames, bans и т.д.) |
| 8 | GA Actions, News, Servers |

GA = куратор (если у админа level 6 и флаг GA).

## Токены и сессия

- При 401 — редирект на dashboard
- При `server_locked` (403) — редирект на /unlock
- Токен хранится в localStorage как `admin_token`
